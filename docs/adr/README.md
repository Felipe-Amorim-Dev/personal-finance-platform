# Architecture Decision Records

Este diretório contém os **Architecture Decision Records (ADRs)** do **Personal Finance Platform**.

ADRs são utilizados para registrar decisões arquiteturais relevantes realizadas durante o desenvolvimento do sistema.

O objetivo é documentar não apenas **qual decisão foi tomada**, mas também **por que ela foi tomada**.

---

Status

Decisão

Consequências
