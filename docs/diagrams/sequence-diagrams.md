# Diagramas de Sequência

Este documento será utilizado para registrar os principais fluxos de comunicação do **Personal Finance Platform**.

Os diagramas serão adicionados conforme os casos de uso forem implementados.

---

## Fluxos planejados

Entre os fluxos que poderão ser documentados estão:

- Cadastro de usuário;
- Autenticação;
- Renovação de token;
- Cadastro de receita;
- Cadastro de despesa;
- Processamento de despesas recorrentes;
- Agendamento de automações;
- Captura automática de contas;
- Processamento de faturas recebidas por e-mail;
- Consulta ao agente financeiro;
- Processamento analítico através do Databricks.

---

## Diretriz

Cada diagrama de sequência deverá representar um fluxo real implementado ou em desenvolvimento.

Fluxos ainda não definidos poderão permanecer apenas como itens planejados até o início de sua implementação.
